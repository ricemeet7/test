# Othello Game

A browser-based Othello (Reversi) game featuring AI opponents with selectable difficulty levels and a modern UI.

## Running

Open `index.html` in a modern browser.

## Gameplay

- You play as black, the AI plays as white.
- Choose the AI difficulty (Easy, Medium, Hard) and start a new game.
- Click highlighted squares to place pieces.
- The game ends when neither player has a valid move; the player with more pieces wins.

## Development

No build step or server is required; the project uses vanilla HTML, CSS and JavaScript.
